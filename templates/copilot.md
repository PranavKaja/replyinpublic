# Reply drafts

The dashboard does not invent a reply. A draft is filled only from a manual, FAQ, or care page that has been saved for that brand.

For each focus brand, add one file in `manuals/` when the pages are chosen:

- Instant Pot
- KitchenAid
- Traeger
- Ninja
- De'Longhi

Each file should list the product, the source URL, and the passages that are safe to quote. Until those files exist, the preview shows no suggested reply.
